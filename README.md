Entry for the [Funniest Time Machine Warning Label](https://make.fun/c/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) bounty on make.fun — one warning label of 120 characters or fewer, judged in private rounds by an AI comedy judge.

## The entry

> WARNING: Passengers who kill their own grandfather will be charged a cleaning fee.

Ten candidates were drafted and scored in [CANDIDATES.md](CANDIDATES.md); this one won for turning the grandfather paradox into a deadpan bureaucratic penalty, with the punchline saved for the last three words.

## How it works

`main.ts` writes the label to `/output/entry.txt` (82 characters) and refuses to write anything outside the 1–120 character gate.

```sh
node main.ts
cat /output/entry.txt
```
